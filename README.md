## 👨‍💻 Sobre mim

Engenheiro de Software Backend com **mais de 3 anos e meio** de experiência no desenvolvimento de soluções escaláveis com **.NET**. Atualmente no **Banco PAN** (fintech), no time de Recuperação de Crédito, em um ecossistema que atende **mais de 32 milhões de clientes**. Cursando pós-graduação em **Arquitetura de Software na FIAP** e graduado em Análise e Desenvolvimento de Sistemas (FIAP)

## 🛠️ Tecnologias

**Backend:** C#, .NET Core, ASP.NET Core, APIs REST, microsserviços
**Mensageria e cache:** Kafka, Redis
**Cloud (AWS):** EKS, Lambda, DynamoDB, S3, RDS, EC2, SQS, SNS
**Bancos de dados:** SQL Server, Oracle, MySQL, PostgreSQL, MongoDB, DynamoDB · EF Core, Dapper
**Qualidade e entrega:** xUnit, SonarQube, Docker, Kubernetes, CI/CD no Azure DevOps
**Arquitetura:** Clean Architecture, Onion Architecture, DDD, CQRS, SOLID
